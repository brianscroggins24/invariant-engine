# Synthetic capture cases

`cases.json` records small, offline-only examples used to document the bounded
Milestone 5 input and venue-native response shapes. They are synthetic fixtures,
not captured venue data, replay input, proof of current venue behavior, or live
access evidence. No credential, key identifier, signature, or signing material is
present.

The implementation tests construct additional boundary payloads in memory so
large limit cases do not become repository artifacts.

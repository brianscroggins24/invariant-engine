# Milestone 2.3 constraint fixtures

This directory contains small, local, versioned, synthetic fixture records
used by the deterministic constraint compiler, observation boundary, and
interval evaluator. `cases.json` contains labeled compilation mappings,
evaluation status expectations, and failure labels consumed by tests. Fixture
records are provenance-bearing and are not authoritative market rules.

These fixtures are not semantic review, production market rules, executable
opportunities, provider benchmarks, trading authorization, or live data.
They contain no credentials and are never sent to a venue, network, or model.
